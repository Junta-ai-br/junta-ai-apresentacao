# Junta.ai | Apresentação Oficial 💜

**Converse. Entenda. Planeje.**

Apresentação interativa do **Junta.ai**, um assistente financeiro conversacional desenvolvido para ajudar pessoas a compreender, organizar e planejar suas finanças de maneira simples, acessível e humanizada.

O projeto nasceu como trabalho final do curso de **Desenvolvimento Full Stack da +praTi e Codifica**, com a proposta de explorar como inteligência artificial, engenharia de software e experiência do usuário podem contribuir para uma relação mais consciente e tranquila com o dinheiro.

## 🚀 Acesse a apresentação

**[Visualizar apresentação interativa](https://junta-ai-apresentacao.vercel.app/)**

A apresentação foi desenvolvida para execução diretamente no navegador, preservando animações, transições e elementos visuais interativos.
Use as setas do teclado para navegar na apresentação.

## 💡 O que você vai encontrar

Organizada em sete slides, a apresentação percorre os principais aspectos do projeto:

1. **Junta.ai:** propósito e proposta de valor.
2. **O problema:** limitações das ferramentas tradicionais de organização financeira.
3. **Ciência aplicada:** bem-estar financeiro, comportamento e experiência do usuário.
4. **Como funciona:** da conversa em linguagem natural à organização das informações.
5. **Demonstração:** acesso ao produto em funcionamento.
6. **Arquitetura:** integração entre frontend, backend, inteligência artificial e segurança.
7. **Encerramento:** convite para conhecer e experimentar o Junta.ai.

## 🛠️ Tecnologias utilizadas

Esta apresentação foi construída como uma aplicação web estática, utilizando:

- **HTML5 e CSS3:** estrutura, identidade visual e animações.
- **JavaScript:** comportamento e interatividade.
- **Reveal.js:** navegação e transições entre slides.
- **Three.js / WebGL:** elementos tridimensionais e efeitos visuais.
- **SVG:** ícones, diagramas e elementos gráficos.
- **Vercel:** hospedagem e publicação contínua.
