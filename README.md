# Junta.ai — apresentação final

Site estático com os sete slides originais, sem reconstrução ou alteração do layout.

## Publicar no Vercel
1. Crie um projeto novo no Vercel, separado do site principal.
2. Faça upload desta pasta (ou conecte um repositório GitHub que contenha `index.html` na raiz).
3. Framework Preset: **Other**. Build Command: **vazio**. Output Directory: **.** (raiz).
4. Publique e compartilhe a URL gerada `*.vercel.app`.
5. Opcionalmente configure o subdomínio `apresentacao.junta-ai.com` no projeto e crie o DNS conforme instruções da Vercel/Hostinger.

## Navegação
Use as setas do teclado para navegar. Pressione `S` para abrir as notas do apresentador (podem ser exibidas a quem abrir essa opção).

## Dependências
A página carrega Reveal.js, Three.js e fontes Google via CDN, portanto requer conexão à internet. Não contém backend nem formulário.
